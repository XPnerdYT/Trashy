## Trashy AI Vision
### Download
Go to the project releases and download the latest version.
### Instructions
To run the AI recognition program, follow the instructions below.
1. Install Python 3.10 or 3.11 from https://www.python.org/downloads/release/python-3119/. Ensure "Add python.exe to PATH" is checked during setup.
2. Run start.bat
3. Play around with putting items into the frame for the program to auto-classify it.
4. Press q to exit.
---
#### Notes
* The first run requires an internet connection
* The app needs webcam attached
* If Windows Defender/SmartScreen flags the exe choose "More info" -> "Run anyway"
* The program is in its very early development stages and accuracy of the vision system is not perfect
